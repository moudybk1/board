Date: 2026-09-16

scope per the antislop-code scope guardrail.

The dominant pattern is length, not decoration. Nearly every finding is a comment
whose content is legitimately valuable, which is exactly the case antislop-code
warns goes unexamined: "Value is not length."

## HIGH

### 1. Decorative separators in `.env.example`

`.env.example`, four blocks. Full-width `# ---...---` rules wrapping section
labels (`Database`, `Chain`, `Wallet sign-in`, `Service-to-service`).

Rule: antislop-code, Decorative Separators (R-31). The decoration is the message;
a label wrapped in rules adds no information.

Fix: drop the rules, keep the plain label line.

## LOW

### 19. Route doc blocks that echo the signature

Roughly 20 one-line blocks of the form
`/** POST /api/ludo/rooms/[roomId]/skip · skip the active seat's turn. */`,
where the route path and the handler name already carry it.

Rule: antislop-code, Signature Echo (R-31).

Note: this matches the convention already used by every untouched route in the
repo. Removing them only in the rewritten files would make the API layer
inconsistent. Recommend leaving these, or handling them repo-wide as a separate
pass. The blocks that document a body shape or an auth requirement earn their
place and stay either way.
